# Расписание МАБиУ (Веб-версия для iPhone и ПК)

Современное веб-приложение расписания занятий Международной академии бизнеса и управления (МАБиУ), разработанное специально для удобного использования на iPhone (iOS), Android и компьютерах.

---

## ✨ Возможности

- **Полная совместимость с iPhone (iOS PWA):** Добавляется на рабочий стол iPhone в один клик через Safari («Поделиться» → «На экран „Домой“») и работает как полноценное нативное приложение на весь экран без адресной строки браузера.
- **Только 26 набор:** В списке отображаются актуальные группы набора 26 (`ЛОМО26/СО`, `ПЛ26/БО`, `МО26/БО` и др.).
- **Живой таймер пар (обновление каждую секунду):**
  - **Идёт пара:** показывает обратный отсчёт до конца пары («Осталось 14:35 (до 15:05)») и аудиторию.
  - **Перерыв:** обратный отсчёт до начала следующей пары («Перерыв: до пары 10:00 (до 15:20)»).
  - **До первой пары:** время до начала занятий.
  - **Пары закончились:** «Пары на сегодня закончились! Завтра к 10:30 (1 пара)».
  - **Выходной день:** «Сегодня занятий нет 🎉» с указанием, когда следующие пары.
- **Свайпы и карусель дней:** Быстрое переключение между днями недели свайпом влево/вправо или нажатием на день, кнопка «Сегодня» для мгновенного возврата.
- **Совместные пары:** Отображение бейджа «Совместно с: ГД26/БО, ПЛ26/БО...».
- **Автоисправление опечаток в датах:** Умный алгоритм сопоставляет день недели и даты в столбцах Excel, исправляя ошибки составителей расписания.
- **Ручная загрузка XLSX прямо в браузере:** Если расписание ещё не выложили на диск, можно перетащить или выбрать `.xlsx` файл в настройках — он моментально разберётся прямо в браузере без отправки на сторонние серверы.
- **Никакой почты:** Полная синхронизация исключительно по открытой ссылке Яндекс.Диска.
- **Работа офлайн:** Благодаря Service Worker приложение сохраняет расписание и открывается даже без интернета.

## 🚀 Инструкция по развёртыванию

### Вариант 1: Деплой на Vercel (Рекомендуется ⭐)
*Vercel бесплатен и автоматически запускает серверную функцию `/api/schedule`, которая сама периодически скачивает свежий .xlsx файл с Яндекс.Диска.*

1. Зарегистрируйтесь на [Vercel](https://vercel.com) (можно войти через GitHub).
2. Загрузите папку `web_app` в новый репозиторий на GitHub (или используйте Vercel CLI / импорт).
3. В панели Vercel нажмите **«Add New Project»** → выберите ваш репозиторий.
4. Нажмите кнопку **«Deploy»**.
5. Готово! Вы получите красивую постоянную ссылку вида `https://mabiu-schedule.vercel.app`, которую можно отправить друзьям.

---

### Вариант 2: Деплой на GitHub Pages (Бесплатно)
1. Создайте публичный репозиторий на [GitHub](https://github.com), например `mabiu-schedule`.
2. Скопируйте содержимое папки `web_app` в корень репозитория.
3. В настройках репозитория откройте **Settings** → **Pages** → в разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`.
4. Нажмите **Save**. Через минуту сайт будет доступен по ссылке вида `https://ваш-логин.github.io/mabiu-schedule/`.

## 📱 Как установить на iPhone (iOS)

1. Откройте ссылку на сайт в браузере **Safari**.
2. Внизу экрана нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх).
3. Прокрутите список вниз и нажмите **«На экран „Домой“»** (Add to Home Screen).
4. Нажмите **«Добавить»** в правом верхнем углу.
5. На рабочем столе появится иконка «Расписание» с синей эмблемой. При запуске сайт открывается во весь экран без рамок браузера!

## 🛠 Локальный запуск для проверки

Для проверки на компьютере достаточно запустить локальный веб-сервер, например через Python:

```bash
cd web_app
python -m http.server 8080
```

После этого откройте в браузере: `http://localhost:8080`.
